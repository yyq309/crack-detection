# Gemini 335 堤坝现场采集建议

公开 DamCrack 图片可扩充 RGB 裂缝训练样本，但不能代替本项目实际相机和现场材质的数据。现场采集同时要覆盖确认裂缝、天然石缝、施工缝、剥落、渗水痕迹和正常坝面。对于难以判断的区域标为 `uncertain`，先不放入二分类训练。

## 每次拍摄保存

- 原始 RGB 图片；原始 16 位深度图；对齐到 RGB 的深度图。不要只保存伪彩色深度截图。
- 深度数值的单位或比例、RGB/深度相机内参、两相机外参、对齐方式、时间戳和设备型号/固件版本。
- 坝体/拍摄点编号、日期、距离、视角、光照和表面干湿状态；同一位置的全景和近景关联 ID。
- 一张带标尺的近景，并测量标尺所在平面与被测表面的关系；宽度评估还需实地校准。

相机的 RGB 与深度视场、分辨率和有效距离可查 [Gemini 335 产品规格](https://www.orbbec.com/products/stereo-vision-camera/gemini-335/)；深度与 RGB 对齐、时间同步及标定参数见 [Orbbec 官方功能说明](https://doc.orbbec.com/documentation/Orbbec%20Gemini%20330%20Series%20Documentation/Exploring%20Unique%20Features%20of%20The%20Camera)。深度图的距离精度不能直接当成细裂缝宽度精度。

## 标注与划分

每张原图记录 `crack / no_crack / uncertain`，并单独标出 `natural_joint`、`construction_joint`、`spalling` 等干扰。裂缝图再画裂缝掩膜，并由现场人员确认 LV0–LV3 等级；只有包含裂缝的图才进入等级评估。保留同一原图裁出的所有小块、同一连续坝面和同一次拍摄会话在同一数据划分内。先固定独立测试地点，再从其余地点制作训练裁片。

首批数据应优先采集与裂缝外观接近的**石材自然拼缝**，以及细小真实裂缝。记录每种场景的漏检和误报，并在确定标注后再微调模型。公开坝体数据暂作训练补充，不用它替代 Gemini 335 的现场验证。
