# Original handoff scripts

These are the 13 Python scripts from the original handoff package, retained to preserve training and analysis history. Their original folder assumptions refer to the handoff package layout and are not the maintained entry points in this repository. Use `scripts/detect_and_grade.py` for a fresh clone.

The original author attribution is retained in the source and in the project README. No license was supplied with the handoff; this repository does not assert a new license for those files or weights.
